# Backend

Reserved for the Java Spring Boot application. It will own authentication,
permissions, imports, jobs, transport records, recommendations, and database access.

Application source will use `src/main/java/`, resources `src/main/resources/`,
and automated tests `src/test/java/`. Add the build definition and pin application
dependencies when the implementation is initialised.

See the [architecture](../docs/07-architecture.md) and
[configuration example](../config/.env.example).
