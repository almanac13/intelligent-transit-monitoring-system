# Intelligent Transit Monitoring System

## Diploma Project
Development of an Intelligent Web Service to Improve the Efficiency
of Urban Public Transport.

## Description
A web service for analysing urban public transport data,
detecting unusual operations, and presenting evidence for investigation.
