# Intelligent Transit Monitoring System

## Diploma Project
Development of an Intelligent Web Service to Improve the Efficiency
of Urban Public Transport.

## Description
A web service for analysing urban public transport data,
detecting unusual operations, and presenting evidence for investigation.

## Student
Nurassyl Meirbek — SE-2415, Astana IT University.

## Supervisor
Madina Askarovna Yermaganbetova — Associate Professor.

## Current Status
Research and design stage. Research documents and a clickable UX prototype
are available. Application implementation is planned.

## Planned Technologies
Java, Spring Boot, Python, FastAPI, PostgreSQL, React, and TypeScript.

## Documentation

See the [documentation index](docs/README.md) for the proposal, research,
comparisons, requirements, architecture, UX, verification plan, and project risks.

## Run the UX Prototype

Open [frontend/prototype/index.html](frontend/prototype/index.html) in a modern
browser. No server, installation, or internet connection is required.
The prototype uses illustrative data and simulated interactions.
See the [prototype guide](frontend/prototype/README.md) for scenarios and limitations.

## Repository Structure

```text
docs/                 Numbered Markdown documents and documentation index
frontend/
  prototype/          Self-contained clickable HTML prototype and guide
backend/              Reserved for the Spring Boot application
analysis/             Reserved for Python analysis code
config/               Configuration examples
diagrams/
  src/                Editable Mermaid architecture diagrams
  exports/            Reserved for rendered diagrams
tests/
  fixtures/           Reserved for test input data
```

Document numbering follows the supplied materials. Planned application folders
remain placeholders until implementation begins. Local configuration can be
based on [config/.env.example](config/.env.example).
